# Minesweeper — Сапер

Курсова робота з об'єктно-орієнтованого програмування.

## Запуск

Точка входу `Main.java`.

## Можливості

- Три стандартні рівні складності та графічний вибір власного поля (5×5 — 36×24).
- Безпечний перший хід, прапорці, відкриття сусідів через Shift+ЛКМ або подвійне натискання.
- Три підказки на партію, ручна пауза й автопауза під час відкриття діалогів або згортання вікна.
- Історія ігор, загальна статистика, топ-10 рекордів за кожною стандартною складністю.
- Перемоги з підказками відображаються в історії, але не враховуються в рейтингу.
- Дві теми з попереднім переглядом; вибрана тема зберігається.
- Ручне збереження і автоматичне збереження незакінченої партії при закритті. Після запуску збережена гра відкривається на паузі.
- Підтвердження початку нової партії, якщо поточна вже розпочата.

## Структура

- `model` — поле, клітинки, параметри гри, стан партії, підказки та результати.
- `controller` — керування партією, таймер та причини паузи.
- `service` — обчислення статистики.
- `storage` — інтерфейси й файлове збереження історії, поточної гри та налаштувань.
- `ui` — головне вікно, компоненти, діалоги та теми оформлення.
- `record` — читання рекордів, збережених попередньою версією гри.

Дані зберігаються в папці `data/`. Файл `records.properties`
